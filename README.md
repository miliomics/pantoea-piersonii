# _Pantoea piersonii_
Genomic epidemiology, diagnostic misidentification, antimicrobial resistance and niche-associated physiology across clinical, terrestrial and space-associated isolates.

_Pantoea piersonii_ (basonym _Kalamiella piersonii_), is a Gram-negative bacterium within the Erwiniaceae family. Originally described as _K. piersonii_ gen. nov. sp. nov. from the International Space Station in 2016 (Singh et al., 2016), it is increasingly being detected in clinical, human-associated and terrestrial environments. 

This repository contains the data-processing workflows and supporting resources used to investigate its identification, population structure, antimicrobial resistance, aerobactin locus, metabolic characteristics and pathogenic potential.
